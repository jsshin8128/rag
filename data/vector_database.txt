벡터 데이터베이스 완전 이해

벡터 데이터베이스(Vector Database)는 고차원 벡터 데이터를 효율적으로 저장하고 유사도 검색을 수행하는 특수 데이터베이스입니다. RAG 시스템의 핵심 구성 요소입니다.

벡터 유사도 검색
벡터 데이터베이스의 핵심 기능은 유사도 검색(Similarity Search)입니다. 코사인 유사도(Cosine Similarity)는 두 벡터 간의 각도를 측정합니다. 유클리드 거리(Euclidean Distance)는 두 벡터 간의 직선 거리를 계산합니다. 내적(Dot Product)은 벡터의 크기와 방향을 모두 고려합니다. RAG에서는 주로 코사인 유사도를 사용합니다.

주요 벡터 데이터베이스 종류
Chroma는 오픈소스 벡터 데이터베이스로 로컬 환경에서 쉽게 사용할 수 있어 개발과 프로토타이핑에 적합합니다. Pinecone은 완전 관리형 클라우드 벡터 데이터베이스로 대규모 프로덕션 환경에 적합합니다. Weaviate는 오픈소스 벡터 검색 엔진으로 그래프 기반 데이터 구조를 지원합니다. Milvus는 대규모 벡터 데이터 처리에 특화된 오픈소스 벡터 데이터베이스입니다. FAISS는 Meta가 개발한 벡터 유사도 검색 라이브러리입니다.

Chroma 특징
이번 실습에서 사용하는 Chroma는 Python 네이티브 환경에서 매우 간편하게 사용할 수 있습니다. 영속성 저장(Persistent Storage)을 지원하여 프로그램 종료 후에도 데이터가 유지됩니다. LangChain과의 통합이 뛰어나 RAG 파이프라인 구축이 쉽습니다. 컬렉션(Collection) 단위로 데이터를 관리하며, 메타데이터 필터링도 지원합니다.

인덱싱 방법
벡터 데이터베이스는 빠른 검색을 위해 다양한 인덱싱 알고리즘을 사용합니다. HNSW(Hierarchical Navigable Small World)는 계층적 그래프 구조로 빠른 근사 최근접 이웃 검색을 제공합니다. IVF(Inverted File Index)는 벡터를 클러스터로 나누어 검색 범위를 좁힙니다. PQ(Product Quantization)는 벡터를 압축하여 메모리 효율성을 높입니다.

ANN vs KNN
정확한 최근접 이웃 검색(KNN)은 모든 벡터와 비교하므로 정확하지만 느립니다. 근사 최근접 이웃 검색(ANN)은 약간의 정확도를 희생하여 훨씬 빠른 검색을 제공합니다. 실용적인 RAG 시스템에서는 ANN을 사용합니다.

메타데이터 활용
벡터 데이터베이스에는 벡터와 함께 메타데이터를 저장할 수 있습니다. 문서 제목, 작성 날짜, 카테고리, 출처 URL 등을 메타데이터로 저장하면 필터링 검색이 가능합니다. 예를 들어 "2024년 이후 작성된 기술 문서에서만 검색"과 같은 조건을 추가할 수 있습니다.

청크 전략과 벡터 DB 성능
벡터 데이터베이스의 검색 품질은 청크 전략에 크게 의존합니다. 청크가 너무 작으면 문맥이 부족하고, 너무 크면 관련 없는 내용이 포함됩니다. 최적의 청크 크기는 데이터의 특성에 따라 실험을 통해 결정해야 합니다. 일반적으로 500-1000 토큰 크기가 많이 사용됩니다.
